Module for generating WASM for a sequence of instructions.

Some definitions for formality:

Define {$#`is_root` : #`Fork` -> #`bool`$} to be {$ #`is_root`;(f) = f.#`branch`.#`is_none`;(). $}

Let {$F$} be the function mapping a Fork to all Forks reachable from it, with {$F(f)$} a shorthand for {$F(#`Some`;(f))$}:

  F(#`None`)    &= {}\
  F(#`Some`;(f)) &= { f } union
    F(#`Some`;(f.#`branch`?.#`b_if`)) union
    F(f.#`branch`?.#`b_else`).

Let {$L$} be the function mapping a Fork to its leaves:

L(f) = { g in F(f) | #`is_root`;(g) }.

These definitions are used in pre-/post-conditions and invariants for functions and datatypes.
