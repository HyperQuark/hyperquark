fn add_new_root_if_needed(&mut self)

Adds a new root if the exit type stack on the latest tree is empty.

Maintains invariant {$I_r$}: a new root can only be added if the previous root has all leaves with empty type stacks. Inductively {$I_r$} must hold for any value of roots.
