Expand description

A respresentation of a WASM representation of a project. Cannot be created directly; use TryFrom<IrProject>.

Fields§

§flags: WasmFlags§steps: Rc<RefCell<Vec<StepFunc>>>

step funcs corresponding to the non-inlined steps, in the same order (hopefully)

§events: BTreeMap<Event, Vec<u32>>

maps an event to a list of step_func indices (NOT function indices) which are triggered by that event.
